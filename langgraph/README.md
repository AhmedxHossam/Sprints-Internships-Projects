# LangGraph Projects

### [Financial Report Evaluator–Optimizer](01-financial-report-evaluator/)

Generate a financial report, evaluate it against source notes and a structured rubric, and revise it within a fixed budget before accepting it or requesting human review.

### [Nile Insights Research Assistant](02-persistent-research-assistant/)

Research questions with a Tavily search tool and demonstrate retained conversation state, thread isolation, and checkpoint history in LangGraph.

### [Lumina Rescue: Bounded Agentic RAG](03-agentic-rag-rescue/)

Retrieve synthetic local medical research and optional web snippets, critique whether evidence answers the question, and refine retrieval within a deterministic retry budget.

### [AegisHealth: Medical Triage & Human Review](04-medical-triage-workflow/)

Demonstrate confidence-based escalation, separate MCP record access, durable checkpoints, validated agent handoffs, and clinician approval gates using synthetic records.

### [CapitalTrust: EGP Financial Analyst](05-egp-financial-analyst/)

Build an evidence-grounded analyst/reviewer loop with RAG, MCP foreign-exchange fixtures, historical market data, an audit trail, durable checkpoints, and mandatory human review.
