# Agentic RAG Architecture & Incident Analysis

Analyze supplied query logs and propose an enterprise ingestion, retrieval, fallback, and observability architecture.

**Stack:** RAG design · Query-log analysis · Bounded ReAct · Langfuse planning

**Project type:** Architecture deliverable; this folder contains a report, diagram, and source dataset rather than a deployed application.

## How to use

No Python environment or API key is required. Start with the evaluation report, then open the diagram and inspect the source CSV.

A written architecture evaluation, a one-page architecture diagram, and the CSV evidence behind the analysis.

## Scope and limitations

The code snippets and production integrations described in the proposal are design examples. They do not establish deployment, runtime SDK compatibility, or live system performance.

Original training briefs, synthetic data, and design documents are retained where they help explain the implementation. This portfolio is educational work completed during Sprints training; it is not an official Sprints product.
